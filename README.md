# Student Task Tracker

A simple command-line task manager built with Python. It is designed as a beginner project for learning programming and GitHub basics.

## Features
- Add tasks
- View all tasks
- Mark tasks as complete
- Delete tasks
- Save tasks between runs using a JSON file

## Requirements
- Python 3.8 or newer
- No external libraries required

## Run the project
1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run:

   ```bash
   python main.py
   ```
